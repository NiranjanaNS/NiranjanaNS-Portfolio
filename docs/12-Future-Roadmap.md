# Future Roadmap

## Purpose

This document captures ideas that should not distract from version 1.0 but may improve the
portfolio later.

## Version 1.1

- Add individual project case study pages.
- Add polished engineering notes from the development journal.
- Add more project screenshots or short demos.
- Improve Open Graph preview assets.

## Version 1.2

- Add an Engineering Notes page.
- Add project filtering by stack, domain, and complexity.
- Add a richer architecture gallery.
- Add a project comparison view for recruiters.

## Version 1.3

- Add optional ambient sound, muted by default.
- Add an in-site command menu.
- Add theme refinements after feedback.
- Add analytics for section engagement, if privacy-friendly.

## Version 2.0

- Consider MDX-based case studies.
- Consider a lightweight CMS only if updates become frequent.
- Consider interactive architecture diagrams.
- Consider a deeper AI Research Center with working mini demos.

## Ideas To Revisit Carefully

- Sound effects.
- Three.js scenes.
- Advanced character animation.
- Cursor tracking.
- Analytics.
- CMS integration.

These can make the product better, but they also increase complexity. Add them only when the core
portfolio is already fast, accessible, and useful.
