# Development Roadmap

## Overall Roadmap

```text
Phase 1: Product Discovery and Documentation
Phase 2: UX, Design, and Architecture
Phase 3: Frontend Foundation
Phase 4: Scroll Engine
Phase 5: Core Portfolio Sections
Phase 6: Backend with NestJS
Phase 7: CMS and Dashboard
Phase 8: Production and Deployment
```

## Phase 1: Product Discovery and Documentation

Goal: Define the product before building the interface.

Status: complete.

Deliverables:

- Vision document.
- Product requirements document.
- Goals and success metrics.
- Inspiration research.
- Design system.
- Portfolio world map.
- Animation system.
- Technical architecture.

## Phase 2: UX, Design, and Architecture

Goal: Design every scene before writing UI components.

Deliverables:

- Scene blueprint.
- Low-fidelity wireframes.
- Character sheet.
- Design tokens.
- Component tree.
- State diagram.
- Interaction map.
- Detailed animation specification.
- Backend architecture decision.
- Monorepo direction.

## Phase 3: Frontend Foundation

Goal: Build the technical foundation for the portfolio experience.

Deliverables:

- pnpm workspace setup.
- Next.js setup.
- TypeScript configuration.
- Tailwind configuration.
- ESLint and Prettier.
- Husky and Commitlint.
- Font setup.
- Base layout.
- Theme tokens.
- Component inventory page.
- Lucide setup.
- Shadcn UI setup.

## Phase 4: Scroll Engine

Goal: Build the movement system before building full content scenes.

Deliverables:

- Smooth scrolling setup.
- Pinned container.
- Horizontal world movement.
- Scene detection.
- Animation controller.
- Character state controller.
- Responsive fallback.
- Reduced-motion support.

## Phase 5: Core Portfolio Sections

Goal: Build each scene as a polished, responsive section.

Sprints:

- Loading and Hero.
- About Forest.
- University.
- Skills Forest.
- Developer City.
- Project Laboratory.
- AI Research Center.
- Engineering Room.
- GitHub Galaxy.
- Contact Camp.

## Phase 6: Backend with NestJS

Goal: Add backend features only where they strengthen the product.

Deliverables:

- NestJS API.
- Prisma.
- PostgreSQL.
- Contact requests.
- Admin auth.
- Projects API.
- Skills API.
- Analytics API.
- GitHub sync API.
- Swagger documentation.
- Docker setup.

## Phase 7: CMS and Dashboard

Goal: Make the portfolio maintainable without editing code for every content update.

Deliverables:

- Admin login.
- Manage projects.
- Manage skills.
- Manage timeline.
- Manage achievements.
- Review contact messages.
- Publish updates.

## Phase 8: Production and Deployment

Goal: Make the full-stack product production-ready.

Deliverables:

- Docker.
- CI/CD.
- GitHub Actions.
- Web deployment.
- API deployment.
- Database deployment.
- Monitoring.
- Lighthouse audit.
- Accessibility audit.
- SEO audit.
