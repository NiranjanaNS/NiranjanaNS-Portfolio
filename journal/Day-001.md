# Day 001

## Today I Built

- Initialized the product foundation for NiranjanaNS Engineering Journey.
- Created product discovery documentation.
- Added a PRD and generated a PDF version.
- Set up the first repository structure for docs, design, wireframes, scripts, public assets, and src.

## Problems I Faced

- The project needed a clear product direction before UI implementation.
- The documentation structure needed to be organized so it can scale.
- The PRD needed both a GitHub-friendly Markdown version and a shareable PDF version.

## How I Solved Them

- Treated the portfolio as a product instead of a basic website.
- Created separate documents for vision, goals, personas, journey, sitemap, design, animation,
  architecture, deployment, roadmap, and decisions.
- Added a local script to regenerate the PRD PDF from Markdown.

## What I Learned

- A strong portfolio starts with product thinking, not just visuals.
- Documentation can become part of the engineering proof.
- A clear repository structure makes future development easier.
