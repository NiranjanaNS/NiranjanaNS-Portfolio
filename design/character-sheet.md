# Character Sheet

## Character Role

The character is a reusable personal mascot for NiranjanaNS Engineering Journey. It should guide
the visitor through the portfolio without becoming more important than the content.

## Character Name

Working name: Nira

This can change later if Niranjana wants a different name.

## Visual Direction

- Minimal vector developer.
- Professional, friendly, and calm.
- Not anime.
- Not realistic portrait.
- Readable at small sizes.
- Built from reusable shapes that can be animated.

## Core Features

### Hair

- Long hair.
- Simple shape language.
- Subtle motion during walk and idle states.

### Outfit

- Hoodie.
- Slim backpack straps.
- Comfortable developer look.
- Dark base color with blue accent.

### Shoes

- Minimal sneakers.
- Simple soles for clean walk-cycle animation.

### Bag

- Backpack that visually fills with experience over the journey.
- Optional badges for projects, AI, backend, and deployment.

### Laptop

- Small laptop carried or used in project and engineering scenes.
- Can show a simple glowing screen.

### Accessories

- Smart watch.
- Small glowing blue bracelet.
- Optional small pin on backpack.

## Character Views

### Front

Purpose:

- Used for idle, greeting, and final contact moments.

Needed details:

- Face shape.
- Hair silhouette.
- Hoodie front.
- Backpack straps.
- Bracelet.

### Side

Purpose:

- Used for horizontal journey movement.

Needed details:

- Walking silhouette.
- Backpack shape.
- Hair movement.
- Shoe positions.

### Back

Purpose:

- Used sparingly for launch or looking-at-diagram moments.

Needed details:

- Backpack.
- Hoodie back.
- Hair shape.

## Pose Library

### Idle

- Feet planted.
- Slight breathing motion.
- Occasional blink.
- Hair moves subtly.

### Walk

- Loopable walking cycle.
- Backpack bounces very slightly.
- Hair follows motion.

### Run

- Used only for high scroll velocity.
- Faster walk cycle, not exaggerated.

### Jump

- Optional.
- Use for milestone or achievement reveal only.

### Wave

- Used in contact or ending scene.

### Think

- Used in engineering room or project lab.

## Expression Library

- Neutral focused.
- Small smile.
- Curious.
- Confident.
- Thinking.

## Animation States

```text
idle
walking
running
paused
thinking
waving
```

## Brand Reuse

The same character can later be used for:

- Portfolio.
- Resume visual accents.
- GitHub profile README.
- LinkedIn posts.
- Project case study illustrations.
- Stickers or thumbnails.

## Design Constraints

- Avoid too many tiny details.
- Avoid facial realism.
- Avoid random generated variants.
- Keep proportions consistent.
- Keep shapes easy to redraw in SVG or animate with CSS/GSAP.

## Open Decisions

- Final character name.
- Exact hoodie color.
- Hair style details.
- Whether the backpack visibly changes per scene.
- Whether the character is SVG, Lottie, or CSS/SVG hybrid.
