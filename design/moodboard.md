# Moodboard

Collect visual references before designing the portfolio UI. This file is the written companion to
future moodboard images or PDFs.

## Visual Keywords

- Premium
- Minimal
- Engineering-focused
- Cinematic
- Calm dark mode
- Slightly futuristic
- Trustworthy
- Playful in small details

### Buttons

Collect examples of:

### Typography

Collect examples of:

- Compact technical labels.
- Case study body text.

labeling.
